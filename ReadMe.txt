Creating Relations:

The SQL commands to create relations are available in create.sql file which on running create 12 tables.

-----------------------------------

We have used Python’s random library along with some custom data generators to automatically populate the database tables with the required number of records. This allows for realistic and scalable test data without manual entry

-----------------------------------

Data Generation Codes: 

For a detailed understanding of the data generation process, navigate to the following folder: \Data\Data generation codes
This folder contains Python scripts used to generate the database data.

In \Data folder you could find many .sql files, which on running inserts data into all relations.

-----------------------------------

SQL Files:

Instead of generating CSV files, we directly created SQL files for each table.
All individual SQL files are included in a master file: Load.sql
Executing Load.sql will populate the database with all generated data.
